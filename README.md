# Sangu

Sangu hari ini, tenang sampai gajian.

Pencatat keuangan harian yang berjalan sepenuhnya di perangkat: tanpa login, tanpa akun.
Semua data tersimpan di browser/HP masing-masing pengguna dan tidak pernah dikirim ke mana pun.

Notifikasi itu opsional. Kalau dinyalakan, notifikasinya lewat server kecil milik Sangu (Cloudflare):
Pintasan iPhone cuma mengirim nama app (dan nominal kalau diisi) untuk teks notif, dan itu tidak disimpan.

Buka: https://khusnafaiq.github.io/sangu/
